# ArtSource — source-only art workspace

This directory stores original and generated art inputs that should **not** be treated as runtime Unreal assets. Prepared images intended for import are staged under `Content/Aether/Art/ImportReady/` and are tracked in `Content/Aether/Art/2D_ASSET_MANIFEST.json`.

Generated source provenance and exact prompts: `Content/Aether/Art/GENERATED_ART_PROVENANCE.md`.

Do not add third-party assets here without recording the source, license/usage terms, version, and required attribution. Do not place `.uasset`/`.umap` files here; those must be created and saved by the real Unreal Editor.
