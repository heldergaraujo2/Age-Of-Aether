# CC0 Forest Source Assets

These are source GLBs for the optional runtime forest and ground-cover pass. The upstream asset credits identify the **art assets** below as **CC0 1.0**; this is separate from the MIT licence covering the upstream repository's code.

| File | Art source | Licence |
| --- | --- | --- |
| `forest.glb` | [KayKit Forest Nature Pack](https://kaylousberg.itch.io/kaykit-forest) by [Kay Lousberg](https://kaylousberg.com) | CC0 1.0 |
| `nature.glb` | [Nature Kit](https://kenney.nl/assets/nature-kit) by [Kenney](https://kenney.nl), recoloured and vertex-colour-baked in the upstream bundle | CC0 1.0 |

The GLBs were obtained from [`nodexeus/worlds`](https://github.com/nodexeus/worlds/tree/main/public/assets), whose [`CREDITS.md`](https://github.com/nodexeus/worlds/blob/main/public/assets/CREDITS.md) names these sources and licences. Only the two GLB art files are included here; no upstream code is copied.

CC0 1.0 legal text: <https://creativecommons.org/publicdomain/zero/1.0/>. Attribution is not required by CC0, but Kay Lousberg and Kenney are credited here for provenance.
