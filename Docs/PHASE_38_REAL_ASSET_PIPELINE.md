### Default import profile
- FBX source;
- FBX 2020.2 compatibility target;
- scale 1.0 by default;
- Physics Asset enabled for skeletal assets;
- material/texture/animation automatic import disabled by default in the bootstrap profile.

Unreal 5.8 documentation identifies FBX 2020.2 for the FBX pipeline and documents skeletal/static meshes, animation, LODs, morphs, materials and textures. citeturn0search4turn0search7

### Stable runtime asset boundary
The server continues to exchange stable IDs rather than editor-specific visual paths. The Asset Manager remains responsible for Primary Asset discovery/loading; Unreal documents Primary Asset IDs and asynchronous loading through LoadPrimaryAssets. citeturn0search1turn0search2

### Folder convention
Configured under /Game/Aether: Characters, Classes, Items, Monsters, NPC, Maps, UI, Animations, VFX, Audio, Materials, Textures and Testing.

### Import workflow for Helder
1. Open Unreal.
2. Import one source FBX into the appropriate /Game/Aether folder.
3. Verify scale/orientation.
4. Verify skeleton compatibility.
5. Generate/check Physics Asset for skeletal assets.
6. Check materials/textures intentionally.
7. Create/verify sockets.
8. Create/verify the stable AssetID record.
9. Register dependencies and fallback where required.
10. Validate before connecting it to gameplay.

## PENDÊNCIAS
Local Unreal acceptance still needs one real FBX. For the first acceptance asset, use the simplest available skeletal character FBX; do not import the whole asset library yet.

Acceptance: FBX imports; mesh opens; skeleton is valid; Physics Asset exists; material is visible; asset path is correct; stable AssetID resolves; fallback resolves when configured; no missing dependencies; Asset Manager load works; no critical Output Log errors.

## RISCOS
- FBX source quality can cause skeleton, scale, normals or material issues.
- Real Unreal .uasset files are intentionally not generated by GitHub.
- The bootstrap profile favors predictable imports over automatic content generation.
- Production LOD/material/VFX policies will be refined after the first real asset and profiling.
